# Sistema de calificación automática de exámenes de cálculo diferencial mediante OCR y modelos de lenguaje

Proyecto que explora cómo apoyar la calificación de exámenes de cálculo diferencial escritos a mano, digitalizando su contenido mediante OCR y usando modelos de lenguaje como apoyo a la evaluación de los procedimientos. El sistema está pensado como herramienta de apoyo al criterio del docente, no como reemplazo de su decisión final.
